How VoLCA uses it

The volca binary carries GMP, linked statically by the Haskell compiler for
its arbitrary-precision integers. VoLCA takes GMP under the GNU Lesser
General Public License, version 3 or later: its text is in LGPL-3.0.txt, and
the GNU General Public License it builds on is in GPL-3.0.txt.

GMP's source code is at https://gmplib.org/. VoLCA's own source code is
public under the Apache License 2.0 at https://github.com/ccomb/volca, with
the build script that produced the binary, so the binary can be rebuilt
against a modified GMP.
