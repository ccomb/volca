The ILCD Format 1.1 schemas (build 983), unmodified, from the ILCD Format SDK of
the European Commission's JRC, under the licence in
`ILCD_format_and_editor_license.txt`; `xml.xsd` is the W3C schema they import.
The ILCD writer's tests validate every exported file against them with
`xmllint`, through `catalog.xml` so that nothing is fetched from the network.
