- The method CSV has an optional `location` column, after `substance;compartment` like `cas` and `unit`. A factor written for one location keeps it in its own column, and a regionalized collection exported to CSV and read back now gives located factors, where it gave factors named `Water, FR`: the scores of such a re-import can move. A file with a `location` column is refused by an engine older than this one ("unknown key column"); a collection without located factors is written exactly as before.
