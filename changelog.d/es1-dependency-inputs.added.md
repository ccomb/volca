- A database whose inputs are supplied by another loaded database now exports
  as EcoSpold 1. Each such input is written under its supplier's name, place
  and unit, so a reader holding that database beside the file links it there.
  The export refuses an input whose supplier states no place, shares its
  product and place with another activity of its database, carries the name
  of a dataset of the file, or makes its product in a unit the input does not
  convert to.
