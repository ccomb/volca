- An assistant no longer has to choose a method collection to score with. When several are loaded and the call names none, `score_activity`, `score_activities`, `get_impacts`, `get_contributing_flows`, `get_contributing_activities`, the score contributing tools, `compute_sensitivity` and `compare_impacts` take the collection the configuration marks `default = true`, and the `basis` of the answer names it; they refused before. The tools whose answer names no collection (the impact category's factors, mappings and explanations, and the group tools) still refuse and list the collections. The computed quality report takes the default collection the same way.
