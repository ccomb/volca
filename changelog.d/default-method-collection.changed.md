- An assistant no longer has to choose a method collection to score with. When several are loaded and the call names none, `score_activity`, `score_activities`, `get_impacts`, `get_contributing_flows`, `get_contributing_activities`, the score contributing tools, `compute_sensitivity`, `compare_impacts`, `get_group_members` and `get_group_flows` take the collection the configuration marks `default = true`, and the `basis` of the answer names it; they refused before. A tool asked for a scoring set chooses among the collections that hold it. The tools whose answer names no collection (an impact category's factors, mappings and explanations, and `get_group_candidates`) still refuse and list the collections.
